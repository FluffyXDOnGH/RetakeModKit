# Original weapon example source

`generate_carbine.py`, `ExampleCarbine.blend` and `SKM_Example_Carbine.fbx` are an original Codnyx blockout model, created on 2026-11-04 without external geometry, textures or animations. They use the Retake Mod Kit License. The model is a teaching/reference asset, not a finished production weapon.

`BodyContract.json` is the native shared body/pose contract captured from Retake's current hit rig through its supported contract accessor. It contains fixed reference transforms and lower-body posture data, no private gameplay classes or locomotion source clips. The creator generator builds its reference sequences from that data; native pose preparation must still verify the resulting lower-body and skeleton agreement.

`SharedPoseBasis.json` contains the evaluated common lean/clearance reference values for the same game rig. It reconstructs creator-owned reference clips and blend spaces without copying the private animation library. Lean uses compressed evaluation and clearance uses raw evaluation, matching the native baker. Changes to these shared gameplay postures require explicit preparation compatibility review; the originating rig hash is provenance, not a blanket dependency on every later game build number.

`SKM_AuthoringBody.fbx` and `SKM_AuthoringArms.fbx` derive from Epic's installed UE5.8.4 Third Person template, `Templates/TemplateResources/High/Characters/Content/Mannequins/Meshes/SKM_Manny_Simple.uasset`. The original template was read and exported by the pinned pristine UE6 editor. The arms are a skin-weight-selected face subset; the source skeleton, bind poses and skin weights were retained without a DCC skeleton-axis conversion. They are Epic Examples, including modifications, under section 5(b) of Epic's Unreal Engine EULA, and are not licensed as original Codnyx artwork. See the public kit's third-party notice. Import uses an original neutral material; game Animation Blueprints, physics assets, retargeters, outfits, textures and private asset paths are not copied into a creator mod.

`Files.json` binds the exact source bytes used by the example generator. Its absence or a mismatch blocks creation. The SDK's editor-only reference normalization restores the exact published reference transforms after source-file import, refusing changes outside a small rounding envelope and preserving the strict bake checks. Visual, animation, pose-bake, cooked export and gameplay acceptance are tracked separately; these source files alone do not demonstrate compatibility.
